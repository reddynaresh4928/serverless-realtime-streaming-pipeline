# Serverless Real-Time Data Streaming Pipeline

## Description

A cloud-native application that ingests streaming data using Amazon Kinesis, processes it using AWS Lambda, stores it in DynamoDB and S3, and visualizes real-time analytics using a Next.js dashboard.

## Tech Stack

### Frontend
- Next.js (JavaScript)
- Tailwind CSS
- React

### Backend
- AWS Lambda
- Node.js

### AWS Services
- Amazon Kinesis
- DynamoDB
- Amazon S3
- API Gateway
- CloudWatch
